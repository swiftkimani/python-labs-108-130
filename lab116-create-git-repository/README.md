# Lab 116 - Create a Git Repository

This lab is done in the terminal, so there is no Python file to submit.
`git_commands.md` is the log of every command used and what it did.

Quick reference for the core sequence:

```bash
git init
git config user.name "Benard Kimani"
git config user.email "benard@example.com"
git add filename.py
git commit -m "Add filename.py"
git log --oneline
```
